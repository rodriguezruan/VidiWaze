# VidiWaze
Vidi Waze — scientific research project: Arduino data collection to Google Sheets, Flask server and LLM embedding. Starter repo for Arduino sketches, Flask server, and LLM code.

Short description
Vidi Waze is a scientific research project that collects sensor/AP data via Arduino devices, sends measurements to Google Sheets, and uses a Flask server plus embedding/LLM components for analysis and querying.

Repository layout
- arduino/: Arduino sketches and wiring diagrams
- server/: Flask server code that receives data and forwards to Google Sheets
- llm/: Embeddings, vector store, and LLM integration for analysis and QA
- docs/: Research notes, experiment results, and data descriptions
